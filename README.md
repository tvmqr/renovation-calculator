# Renovation Cost Estimator

A modern, fully responsive B2B calculator for estimating apartment renovation costs.  
Built with pure HTML, CSS, and vanilla JavaScript — no frameworks, no libraries, no build steps.

This project is an interactive tool designed to help service businesses increase conversions by letting clients instantly calculate their budget.  
Built 1:1 from a custom wireframe design.

---

## 🛠️ Tech Stack

- **HTML5** – Semantic markup  
- **CSS3** – Grid, Flexbox, CSS Variables, Glassmorphism  
- **Vanilla JavaScript** – DOM, events, custom state management, FormData  
- **Custom UI Components** – Built from scratch (no native `<select>`)  
- **Dark/Light Theme** – Auto-switching via `prefers-color-scheme`  
- **Formspree** – Real form submission without a backend  
- **Responsive design** – fully optimized for mobile and desktop  

---

## ✨ Key Highlights

- 🧠 **Real-time Calculation** – Instantly updates the total, work cost, materials, and services as the user types or clicks.  
- 🎨 **Custom Select Dropdowns** – Native selects replaced with fully custom, animated JS-driven dropdowns that sync with hidden inputs to maintain `FormData` compatibility.  
- 🌗 **System-based Dark Theme** – Automatically adapts to the user's OS settings with a deep glassmorphism aesthetic.  
- 🛡️ **Form Validation** – Prevents submission if the area is `0` or empty.  
- 📬 **Working Form** – Sends a structured payload to Formspree with loading and success states.  
- 💎 **Premium UI** – Glassmorphism, neon glows, multi-layered shadows, and smooth micro-interactions.  
- 📱 **Fully responsive** – the sticky summary card smoothly drops below the form on mobile.
